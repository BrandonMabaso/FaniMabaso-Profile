# Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my background, technical skills, certifications, and selected projects as a final-year Information Technology student.

## About

This portfolio was designed and developed to provide an overview of my experience, technical abilities, and career interests. It highlights my work in data analytics, software development, database systems, and web development.

## Features

- Professional About Me section
- Technical Skills & Expertise
- Project Showcase
- Cisco Certifications
- Downloadable CV
- Responsive design for desktop and mobile
- Contact section with links to GitHub and LinkedIn

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/yourusername/portfolio.git
```

2. Open the project folder.

3. Launch `index.html` in your browser, or run it using the VS Code Live Server extension.
